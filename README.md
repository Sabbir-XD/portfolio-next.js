# Sabbir Hossain | Portfolio

![Portfolio Banner](https://sabbir-protfolio-beta.vercel.app/og-image.jpg)

A modern, elegant, and high-performance personal portfolio built with **Next.js 15**, **Tailwind CSS**, and **Framer Motion**.

**Live Preview:** [https://sabbir-protfolio-beta.vercel.app/](https://sabbir-protfolio-beta.vercel.app/)

---

## ✨ Highlights

- Fully Responsive & Modern Dark UI
- Smooth Scroll Animations
- Interactive Project Showcase with Detailed Pages
- Professional Timeline for Education & Experience
- Glassmorphism + Gradient Design
- Fast Loading & SEO Optimized
- Mobile-First Approach

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: React Icons
- **Deployment**: Vercel
- **Language**: JavaScript / TypeScript

## 📌 Sections

- **Hero** – Eye-catching introduction
- **About Me** – Personal story & stats
- **Skills** – Frontend & Backend with progress bars
- **Education** – Academic timeline
- **Experience** – Internship at Raktch Technology
- **Projects** – Featured works with live demos
- **Contact** – Easy way to reach out

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Sabbir-XD/sabbir-portfolio.git

# Go to project directory
cd sabbir-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
